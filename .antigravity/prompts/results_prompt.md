# Results セクション執筆プロンプト（Web 版 ChatGPT）

## トリガー
- フレーズ: 「リザルト作成して」
- ユーザ操作: 最新の要件、Plan、Methodsドラフト、分析結果（統計出力、引用文等）を共有する。
- システム挙動: 本ファイルを参照し、Results ドラフトを提示する。

## 実行フロー（ChatGPT 用）
1. **準備**
   - Methodsで記述された分析計画に対応する結果が揃っているか確認。
   - APAスタイル等の統計表記ルールを確認（イタリック体、少数位など）。

2. **ドラフト作成（アプローチ別）**

   - **定量研究**
     - **Descriptive Statistics**: 平均、標準偏差、相関行列など。
     - **Main Analysis**: 仮説検定の結果。係数、標準誤差、t値/F値、p値、信頼区間、効果量（d, eta-squared等）を明記。
       - 例: "A t-test revealed a significant difference, *t*(98) = 2.45, *p* = .016, *d* = 0.49."
     - **Tables/Figures**: 「Table 1に示すように…」といった参照を含める（図表本体は別途作成）。

   - **定性研究**
     - **Themes**: 抽出されたテーマごとにサブセクションを構成。
     - **Narrative**: 分析者の解釈と、参加者の語り（Quotes）を織り交ぜて記述。
       - 引用例: "As Participant A stated, '...'"

3. **チェック**
   - 意図せぬ解釈（Discussionの内容）が混じっていないか。Resultsは「事実の報告」に徹する。
   - 仮説の支持/不算出が明確か。

4. **出力**
   - Markdown コードブロックで提示。
   - 不足している統計量などがあれば指摘する。
