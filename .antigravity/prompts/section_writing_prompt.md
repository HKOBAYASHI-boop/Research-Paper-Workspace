# セクション執筆プロンプト（Web 版 ChatGPT）

## トリガー
- フレーズ: 「セクション下書きして」
- ユーザ操作: 対象セクション名（例: Literature Review）、想定語数、関連資料（Plan、文献リスト、データ）を共有する。
- システム挙動: 本ファイルを参照し、指定セクションのドラフトを提示する。

## 実行フロー（ChatGPT 用）
1. **コンテキスト把握**
   - これまでの文脈（Introductionの内容や、全体の論理構成）と整合するように配慮する。
   - 社会科学特有の論述スタイル（論理的、客観的、ヘッジの使用）を意識する。

2. **構成案の提示（必要な場合）**
   - 長文のセクション（例：Literature Review）の場合、まず見出し構成案を提示し、合意を得てから執筆する。

3. **執筆ルール**
   - **パラグラフ構成**: Topic Sentence (主張) → Evidence (根拠・引用) → Analysis/Implication (分析) → Link (次へのつなぎ)。
   - **引用**: `{著者名 雑誌名 年度}` 形式のプレースホルダーを使用。
   - **トーン**: 学術的（Academic）、中立的（Neutral）、三人称（The study...）または一人称（We...）※要件に合わせる。

4. **出力テンプレート**
   ```markdown
   # Section Draft: [Section Name]
   - Target word count: ...
   
   ## Draft
   [Content ...]
   
   ## Notes
   - 引用未確認箇所: ...
   - データの追加が必要な箇所: ...
   ```

5. **完了後**
   - 該当ファイルを保存するよう案内する。
