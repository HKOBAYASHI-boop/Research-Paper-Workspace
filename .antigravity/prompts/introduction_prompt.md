# Introduction セクション執筆プロンプト（Web 版 ChatGPT）

## トリガー
- フレーズ: 「イントロ作成して」
- ユーザ操作: 最新の要件、Plan、Abstract、関連エビデンス（文献メモ）を共有する。
- システム挙動: 本ファイルを参照し、Introduction ドラフトを提示する。

## 実行フロー（ChatGPT 用）
1. **前提確認**
   - 社会科学論文における「イントロダクション」の役割（読者の関心を惹きつけ、研究の正当性を主張する）を意識する。
   - **CARSモデル** (Creating a Research Space) 等を参照し、構成を確認する。
     1. **Move 1 (Establish Territory)**: 研究領域の重要性、一般的な知見。
     2. **Move 2 (Establish Niche)**: 既存研究の限界、矛盾、未開拓領域 (Research Gap)。
     3. **Move 3 (Occupy Niche)**: 本研究の目的、仮説、貢献の概要。

2. **情報収集**
   - 引用すべき主要文献（キーとなる理論、対立する先行研究）のリストアップをユーザに依頼。
   - `{著者名 雑誌名 年度}` 形式のプレースホルダー情報を確認。

3. **段落設計**
   - 以下の流れで段落構成を提案し、合意を得る。
     - **Hook**: 現実社会の問題や理論的なパズル。
     - **Literature**: 関連する先行研究の簡潔なレビュー。
     - **Gap**: 何がわかっていないのか。なぜ今それをやる必要があるのか。
     - **The Present Study**: 本研究の問い (RQ)、目的、アプローチ。
     - **Roadmap** (Optional): 論文構成の予告。

4. **ドラフト作成**
   - アカデミックなトーンで執筆。
   - 引用は `{Tanaka 2020}` のようにプレースホルダーで挿入。
   - 仮説提示を行う場合は、それが論理的に導かれるように記述する。

5. **レビューと出力**
   - Markdown コードブロックで提示。
   - `sections/02_introduction.md`（番号は構成による）への保存を促す。
