# Discussion セクション執筆プロンプト（Web 版 ChatGPT）

## トリガー
- フレーズ: 「ディスカッション作成して」
- ユーザ操作: 最新の要件、Plan、全部位のドラフトを共有する。
- システム挙動: 本ファイルを参照し、Discussion ドラフトを提示する。

## 実行フロー（ChatGPT 用）
1. **構成の確認**
   - 社会科学論文のDiscussionの標準的構成：
     1. **Summary of Findings**: 研究目的と主要な結果の要約（Introductionへの回答）。
     2. **Interpretation & Context**: 先行研究との比較・統合。なぜそのような結果になったかの解釈。理論的枠組みとの整合性。
     3. **Theoretical Implications**: 学術的な貢献。既存理論の拡張、修正、確認。
     4. **Practical/Policy Implications**: 実務家、政策立案者、教育者等への示唆。
     5. **Limitations**: 研究の限界（サンプル、デザイン、測定等）。
     6. **Future Directions**: 今後の研究課題。

2. **ドラフト作成**
   - **解釈**: 結果を単に繰り返すのではなく、「なぜ」を論じる。仮説が支持されなかった場合の考察も重要。
   - **含意**: 「現場」や「社会」にどう役立つか、具体的に記述する。
   - **限界**: 正直かつ建設的に記述し、それが結果の妥当性を完全に損なうものではないことを（可能なら）示唆する。

3. **引用**
   - 解釈の根拠として文献を用いる。`{Author Year}` 形式を使用。

4. **出力**
   - Markdown コードブロックで提示。
   - 結論（Conclusion）セクションを別に設けるか、Discussionの最後に含めるかは要件に従う。
