# Conclusion セクション執筆プロンプト（Web 版 ChatGPT）

## トリガー
- フレーズ: 「結論作成して」
- ユーザ操作: 最新の要件、Plan、Discussionドラフトを共有する。
- システム挙動: 本ファイルを参照し、Conclusion ドラフトを提示する。

## 実行フロー（ChatGPT 用）
※ ジャーナルによってはDiscussionに含まれる場合があるため、独立したセクションが必要かを確認する。

1. **前提整理**
   - 論文全体の「take-home message」を抽出。
   - Discussionの要約ではなく、より広い視点での結びを目指す。

2. **ドラフト作成**
   - 2〜4パラグラフ程度で構成。
   - **Summary**: 研究の問いと答えを簡潔に再確認。
   - **Significance**: この研究が社会や学界にもたらす価値を強調。
   - **Final Thought**: 読者に残したい強いメッセージや展望。

3. **注意点**
   - 新しいデータや詳細な議論（Discussionですべきこと）を持ち込まない。
   - 謙虚すぎず、かつ過度な一般化を避けるバランス。

4. **出力**
   - Markdown コードブロックで提示。
